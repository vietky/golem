## Key Findings

### Point Card Calculation
- Golem cards have bonus points based on:
  - Number of different colors (3+ colors = +1, 4 colors = +1)
  - Total crystals (6 total = +1)
  - Minimum bonus is 2 points (via `max(bonusPoints, 2)`)
- Example: `golem_1111` = 10 base points + 2 bonus = 12 points

### Crystal Point Values (End Game)
- Yellow: 0 points
- Green: 1 point each
- Blue: 1 point each  
- Pink: 1 point each
